# 영업 일일 보고 시스템 테스트 명세서

`requirements.md`, `screens.md`, `api-spec.md`를 기준으로 작성한 테스트 케이스 명세서.

## 1. 테스트 개요

- **목적**: 요구사항 정의서의 기능 요구사항(3.1~3.5)이 화면/API 명세대로 정상 동작하는지 검증
- **범위**: 인증, 영업사원 마스터, 고객 마스터, 일일 보고(방문 내역 포함), 댓글, 권한 제어
- **테스트 데이터 전제**
  - 영업사원: `E1000`(김부장, 상급자), `E1001`(홍길동, 팀원), `E1002`(박영희, 팀원)
  - 고객: `C2001`(㈜테스트상사, 담당자 `E1001`)
- **결과 컬럼**: 실행 후 Pass / Fail 기록 (본 문서는 실행 전 템플릿이므로 공란)
